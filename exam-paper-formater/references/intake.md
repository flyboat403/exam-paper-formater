# 信息采集清单（第 2 步必读）

> 采集项共 10 项：① 首部信息 4 项（上卷头、放第 1 页最前面）+
> ② 版式参数 6 项。全部按「识别 → 确认 → 提问」三级处理。
> 本文件是第 2 步的唯一事实源，SKILL.md 只保留入口与追问话术。

## 0. 统一处理方式（三级，逐级降级）

对以下 **4 项首部信息**，**优先从输入文档自动识别/提取**：

1. **识别到且置信度高** → 列出提取结果**让用户确认**（用户可修改）
2. **识别失败 / 低置信 / 缺失** → **用标准问答让用户提供**
3. **用户明确说"随便/默认/你定"** → 用本文件标注的默认值，并在
   交付说明中注明哪项用了默认值

**未经确认不得使用猜测值，也不得擅自替用户决定。**

## 1. ① 首部信息（4 项，放第 1 页最前面）

| # | 项 | 识别来源 | 识别失败处理 | 默认值 |
|---|-----|---------|------------|--------|
| 1 | **学校名称** | 题头/落款校名 | 标准问答索取 | 留空划线（`＿＿＿`），可后补 |
| 2 | **试卷名称**（作大标题，如「物理试卷」「第九章 立体几何单元测验卷」） | 文档标题区 | 标准问答索取 | 用学科+用途拼合（如「数学单元测试卷」），并在交付说明注明是拼合值 |
| 3 | **试卷用途** | 标题/卷首说明里的「单元测验 / 期中检测 / 期末考试 / 模拟考试 / 中考模拟 / 高考模拟 / 月考试卷 / 结业考试 / 课后练习 …」 | 标准问答单选（另加"自定义"项） | 无默认——必问 |
| 4 | **考试时间** | 「考试时间：X 分钟」「120 分钟」等字样 | 标准问答索取 | 90 分钟（交付说明注明） |

## 2. ② 版式参数（6 项，决定 geometry/multicol 取值）

| # | 项 | 选项 | 默认值 |
|---|-----|------|--------|
| 1 | **纸张大小** | A4 / A3 / B5 / A5 / **正度8开（260×370 mm）** / 自定义（mm） | 无——必问 |
| 2 | **方向** | 纵向 / 横向 | 无——必问 |
| 3 | **每页栏数** | 1 栏 / 2 栏 / 3 栏（**三选一**，回答其他数字请用户重选） | 无——必问 |
| 4 | **密封线** | 有 / 无 | 有 |
| 5 | **答案卷** | 生成 / 不生成（独立文件） | 生成；**答案卷纸张默认 A4 竖向** |
| 6 | **答题卡** | 生成 / 不生成 | 生成（纯客观/考场涂卡卷推荐）；**固定 A4 纵向** |

> 版式取舍依据见 SKILL.md 文首「核心原则」三个 trade-off——
> 密度 vs 可读性、密封线 vs 作答空间、答题卡 vs 答案卷。

## 3. 默认整卷配置（用户说"随便/默认/你定"时整套套用）

**A3 / 纵向 / 2 栏 / 密封线：有 / 答案卷：生成 / 答题卡：生成 / 字号 11pt**
（≈121mm 栏宽，兼顾密度与图形空间；学校印刷标准是 A3 横 3 栏，
若用户提到"学校印刷 / 中考 / 高考"，主动建议 A3 横 3 栏。）

## 4. 确认复述（拿到全部值后，开工前必须复述）

学校名称、试卷名称、试卷用途、考试时间、纸张（W×H mm）、方向、栏数、
语言（中文 ctex / 英文 article，按题目内容自动判定，在复述中告知；
用户明确指定时从用户）、密封线、字号、**算出的栏宽**
（栏宽公式与速查表见 `layout.md`）。复述完再进入第 3 步。
